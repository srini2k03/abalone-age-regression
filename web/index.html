How old is this abalone?

Counting shell rings under a microscope is slow and destructive. This model estimates the ring count, and so the age, from seven quick measurements. The tuned XGBoost model behind it (300 trees) runs entirely on this page: no server, no API calls.

Pipeline

One scikit-learn Pipeline is fitted inside every CV fold, so clip bounds and encoders never see validation data. The fitted trees and clip bounds are exported to JSON, and the feature code is ported line for line to JavaScript.

  1. DataUCI abalone.datadownload, cache, SHA-256 fingerprint
  2. ValidateSchema checksdtypes, domains, anomaly report
  3. Split80 / 20 stratified836 hold-out rows set aside
  4. sklearn Pipeline · fitted per fold
    1. QuantileClipperwinsorize at 0.1% / 99.9%
    2. MorphometricFeaturesratios, volume, density, logs
    3. One-hot sexF / I / M
    4. XGBoost on log1p(rings)300 trees, depth 4
  5. Select5×2 repeated K-foldRMSLE leaderboard, Optuna tuning
  6. ExportTrees → JSONparity-checked against Python
  7. ServeYour browserJavaScript evaluator, no backend

Same answers as Python

The export step scores about 200 rows (random rows, every anomalous row and some out-of-range inputs) with the Python pipeline, and scripts/check_web_parity.mjs requires the JavaScript port to match within 1e-4 rings before the site is deployed.
